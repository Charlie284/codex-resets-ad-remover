# Codex Resets Ad Remover 1.0.0

Removes sponsor rails, mobile sponsor cards, and the sponsorship dialog from
codex-resets.com while leaving the reset tracker intact.

## Install

### Chrome

1. Download and extract `codex-resets-ad-remover-chrome-1.0.0.zip`.
2. Open `chrome://extensions`.
3. Enable **Developer mode** and select **Load unpacked**.
4. Choose the extracted directory.

### Firefox and Zen Browser

The Firefox ZIP is unsigned source for testing and Mozilla signing. It can be
loaded temporarily from `about:debugging#/runtime/this-firefox`, but Firefox and
Zen remove temporary extensions when the browser closes. Persistent installation
requires a Mozilla-signed XPI.

Use `SHA256SUMS.txt` to verify the downloaded archives.
