# Firefox Add-ons listing

## Name

Codex Resets Ad Remover

## Summary

Removes sponsor cards from codex-resets.com and restores the tracker layout.

## Description

Keep the Codex reset tracker focused on reset information. This extension removes
the desktop sponsor rails, mobile sponsor card, and sponsorship dialog, then
restores the page width reserved for those placements.

It runs only on codex-resets.com, contains no JavaScript, requests no browser API
permissions, and does not collect or transmit data. It is compatible with Firefox
and Firefox-based Zen Browser.

This is an independent utility and is not affiliated with codex-resets.com or
OpenAI.
