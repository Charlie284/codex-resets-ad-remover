# Privacy policy

Codex Resets Ad Remover does not collect, store, sell, or transmit personal data
or usage data.

The extension contains only a static stylesheet. It executes no JavaScript,
contacts no servers, uses no cookies or browser storage, and requests no browser
API permissions. Its site access is limited to `https://codex-resets.com/*` so it
can hide sponsor elements on that website.

This policy covers the extension itself. The visited website and the browser may
have their own independent privacy practices, which the extension does not
control or modify.
